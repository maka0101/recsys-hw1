# ДЗ-1. Рекомендательные системы

**Расанов Макар**

Датасет: [Amazon Reviews 2023 — Musical Instruments](https://amazon-reviews-2023.github.io/).

Сравнение ItemKNN, iALS, EASE, FM с метаданными и ALS с новым целевым сигналом для рекомендаций top-10.

## Запуск

Для запуска нужны Python 3.12 и зависимости из `requirements.txt`:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Ноутбук открывается в Jupyter или VS Code. Для запуска выбирается Python из `.venv`, затем **Run All**.

Данные загружаются автоматически (около 230 MB). Параметры заданы в начале ноутбука.
Повторный запуск использует локальные данные и кеш.
